# Security policy

## Reporting a vulnerability

Report it privately through GitHub: **Security → Report a vulnerability** on https://github.com/snnbotchway/faultline. Please don't open a public issue.

Include what an attacker can do, the steps to reproduce, and the Faultline and GlitchTip versions. You will get a reply within 7 days.

## Scope

In scope: the Faultline app and its Docker image (the Caddy configuration that serves the app and proxies the backend).

Out of scope: the GlitchTip backend itself. Report those to the GlitchTip project at https://gitlab.com/glitchtip/glitchtip-backend.

## Supported versions

Only the latest release receives security fixes.
