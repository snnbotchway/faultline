# Languages

Faultline is written in English, French and Norwegian Bokmål, the three languages of the stock GlitchTip UI. This page says how the layer works, what stock does, and how the areas still in English get converted.

## How it works

- **Catalogs.** `src/i18n/en/` is the source: one file per area (`common`, `shell`, `auth`, `account`, `settings`, `alerts`, `releases`, `projects`), each a plain object of strings and functions. `Messages` is its type. `src/i18n/fr/` and `src/i18n/nb/` hold the same files, each typed `Messages['area']`, so a missing key, an extra key or a changed argument fails `bun run typecheck`.
- **Loading.** English is in the main bundle. French and Norwegian are one chunk each, fetched only by someone who reads them. `src/main.tsx` awaits `startLocale()` before the first render, so the first paint is already in the right language, the way `public/theme.js` applies the theme.
- **Reading.** A component reads its words with `useT()`, which redraws it when the language changes. Code outside a component (a notice, a page title, an error, a search index) calls `messages()` when it runs, never at module load.
- **Plurals.** `plural(count, { one, other, many? })`, from `@/i18n`, picks the form with `Intl.PluralRules`. `#` is the formatted count. French puts 0 and 1 under `one` and a round million under `many` (`1 000 000 de problèmes`); Norwegian puts 0 under `other`. A count already worded (`1000+`) uses `other` as it is. A count set in mono beside its word uses `counted(count, forms, figure)` from `src/i18n/counted.tsx`, which swaps the leading `#` for the figure.
- **Formats.** `count()` and `percent()` format numbers. A module-level `Intl` formatter is made with `localized((tag) => new Intl.DateTimeFormat(tag, …))` and called as `format()`, so it is remade when the language changes. The tag is the browser's own variant of the chosen language (`en-GB` stays `en-GB`), else the language itself.
- **The choice.** Profile → Language offers "Same as browser" and each language under its own name. The palette lists the other languages under `language`. The pick is saved to the account's `options.language`, so it follows the user to another browser, and this browser keeps a copy in `localStorage.language`, read before the first render. With nothing chosen, Faultline takes the first of `navigator.languages` it has (`no` and `nn` read as Bokmål), else English (`src/lib/language-sync.ts`).
- **Action phrases.** A failure reads "Couldn't {action}. Try again." The action comes from the catalog of the area that failed (`renameAction: 'rename the project'`), so each language can build its own sentence: French joins it with "de" or "d’", Norwegian with "Kunne ikke".

## What stock does

Checked against the 7.0.0 frontend's source map (`/code/dist/main-*.js.map`, `src/main.ts`) and its XLF files.

- **It picks the language from the browser only.** It takes the first of `en`, `fr`, `nb` that `navigator.language` starts with, maps `no` to `nb`, and sets `<html lang>`. There is no URL prefix and no choice in the UI.
- **It never reads `options.language`.** The backend accepts the field (`apps/users/schema.py`, `UserOptions.language: str | None`) and nothing uses it. Faultline uses it to remember the pick.
- **It formats dates and numbers in the UI language.** It registers Angular's locale data for fr and nb and sets `LOCALE_ID`, so the date and number pipes follow the language. Faultline does the same through `Intl`.
- **It translates little.** 69 of its 926 units are marked translated: the nav, sign in and sign up, and a few headings. Faultline reuses those terms where they exist (Problèmes / Problemer, Versions / Utgivelser, Équipes / Grupper, Alertes / Varsler, Paramètres / Innstillinger, Se connecter / Logg inn, clé de sécurité / sikkerhetsnøkkel, codes de récupération / gjenopprettingskoder). Stock's "Epost" is written "e-post", as Bokmål spells it now.

## Style

- **French.** A narrow no-break space (U+202F) before `?`, `!` and `;` and inside « », a no-break space (U+00A0) before `:` and between a number and its unit. Curly apostrophes (’). "Vous", not "tu". Sentence case.
- **Norwegian Bokmål.** « » for quotes, no space inside. "Du". Sentence case. "E-post", "e-postadresse".
- Keep the English as the source of meaning. When English uses one word for two jobs (`Set` as a button and as a value), split the key, since other languages need two words.
- A sentence with a name or link in it is one function that takes it (`notVerified: (email: ReactNode) => …`), never two halves joined in the component, so each language can order the words.

## Every screen is translated

Every screen reads in English, French and Norwegian Bokmål, so Faultline has the locales stock GlitchTip has. New text joins the catalog of its area in all three languages in the same change (`AGENTS.md`). The English `plural` and `ALL_ENVIRONMENTS` that `src/lib/text.ts` used to hold are gone; use `plural()` from `@/i18n` and `common.allEnvironments`.

Search syntax (`is:unresolved`, `level:error`) and the backend's field names stay as they are in every language; only the words around them change.
